What the ads ask for

Number of ads mentioning each topic, out of the 150 that mention AI at all. Keyword-based counts; treat them as approximate.

  • Using AI coding agents well is the most common requirement by far. Ads name the tools (Cursor 26, Copilot 26, Claude Code 23) and stress reviewing, testing and owning what the agent produces.
  • Building LLM features is what sets candidates apart: agents, tool calling, RAG, structured output, MCP.
  • Production concerns appear in senior ads: evals, observability, guardrails, prompt-injection defence, cost control.
  • Training models (PyTorch, fine-tuning) is rarely required for these developer roles, so it is an optional stretch here.
